# Linux Node Health Check

A simple Bash script created while learning Linux and Shell Scripting as part of my DevOps journey.

## What it checks

- Hostname
- System uptime
- CPU usage
- Memory usage
- Disk usage
- Top CPU-consuming processes

## Technologies

- Linux
- Bash / Shell Scripting
- grep
- awk
- ps
- df
- free
- top

## How to use

Clone the repository:

git clone <repository-url>

Move into the directory:

cd linux-node-health-check

Give the script execute permission:

chmod +x node_health_check.sh

Run the health check:

./node_health_check.sh
